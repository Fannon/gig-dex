# Performance mode

**Perform** on a song page or **Perform setlist** on the Setlists page opens a distraction-free stage view. The top bar shows the setlist name, position (for example `2/12`), the entry label (key, transposition, tempo, time signature) and the song title. **← Exit** returns to the song or setlist.

## Moving between songs

Swipe left or right, or press the arrow keys (**Right/Down** for next, **Left/Up** for previous). Repeated songs in a setlist are separate entries with their own key and reading position. A song deleted from the library shows a short notice; keep swiping to continue.

Gig-Dex remembers the current entry and the reading position within each entry on this device, so a reload or an accidental exit brings you back to the same place. Reading positions are not synced or included in backups.

## Performance options

The gear button opens **Performance options**:

- **Fullscreen** hides the browser interface where the browser allows it.
- **Keep screen awake** stops the screen from dimming. The choice is remembered. If the device refuses, the status says so and offers **Retry wake lock**; the lock is requested again when you return to the app and released when you exit. Battery-saving modes can still override it.
- **Reading**: **Fit screen** sizes the song to fit without scrolling (columns as allowed in Settings), **Scroll** uses one scrolling column, **Pages** steps through overlapping pages with large page buttons. The mode is remembered.
- **Beat division** sets the song's time signature for the tempo pulse and saves it to the song.
- **Song controls** shows transpose, font size and chord visibility controls in the stage view.

## Tempo pulse

Songs with a tempo (BPM) show a row of dots that pulse silently on each beat; the first beat has its own color. The pulse starts automatically and restarts when you move to another song. Select the dots to pause or resume; the tooltip shows BPM and time signature. BPM counts quarter notes, so eighth-note signatures such as 6/8 pulse twice per quarter note. This is a visual cue, not an audio metronome or a precision timing source.

## Quick edits

The pencil opens the song editor. **Save** or **Cancel** returns to the same entry in performance mode. Unsaved changes are never discarded without asking.

## Before the gig

Open your setlist once while online, then switch to airplane mode, close the app and reopen it. What you see then is what the stage will see. See [Offline use and updates](offline-and-updates.md).
