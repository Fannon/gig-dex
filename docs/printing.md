# Printing and PDF

**Print** on a song page or on the Setlists page opens a print preview: white paper with dark ink, whatever reading theme you use. Select **Print / Save as PDF** to open the browser's print dialog. Choose your printer, or **Save as PDF** as the destination to get a file; the setlist or song name is suggested as the file name.

## What gets printed

- **A song** prints in the key you were reading it in, including a setlist entry's transposition. The header shows the artist, key, transposition with the original key (for example *Key A · Transposed +2 from G*), tempo and time signature; composer, lyricist and copyright are added when the song has them.
- **A setlist** prints a song list page (name, date, description, and each entry's key, tempo and time signature) followed by every song, numbered, each in its entry's key. Missing songs keep their place as *Missing song*.

Chords use the notation from Settings (standard, German, Nashville or Roman). Long lines wrap at word boundaries and keep chords above their syllables.

## Print options

Each white sheet in the preview starts a new printed page: the song list and every song. The bar above the preview is not printed. Your choices are remembered on this device.

### Seeing what fits on a page

The preview is laid out at the real paper width; on small screens it is scaled down rather than rewrapped. The label in each sheet's corner says **Fits on 1 page** or how many pages it needs. Like the printout, it keeps verses and song-list rows together, moving them to the next page rather than splitting them. In one-column layouts, red **Page 2**, **Page 3** lines show where each printed page begins. With more columns, each page fills its columns in turn, so only the page count is shown. To fit a song on one page, try smaller text, more columns, landscape or narrower margins. The browser's print preview remains the final word.

### Options

- **Paper**: A4 or Letter. Used for the page count and as the print dialog's starting paper size.
- **Orientation**: portrait or landscape.
- **Margins**: 5 to 25 mm (default 10 mm).
- **Chords**: turn off for lyrics-only sheets.
- **Comments**: ChordPro `{comment}` lines, such as performance notes or the demo songs' tips. Off by default.
- **Columns**: 1 to 4 per page (default 2). Three or four columns suit landscape.
- **Text size**: 8 to 24 pt (default 11 pt).
- **Key** (shown when something is transposed): print as transposed (default) or in the original key.
- **Song list page** (setlists): include it, leave it out, or print only the song list (for example as a stage set list).

Headers and footers are set in the browser's print dialog. Choosing another paper size, margins or orientation there overrides these options, and the page count no longer applies. If a browser ignores the orientation or margins, set them in its print dialog instead.
